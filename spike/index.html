    What to try

    1. Sign in with each method you'd like to use.
    2. Close the page completely and open it again: you should still be signed in.
    3. Turn on Airplane Mode, tap Save a test note, then close and reopen the page. The note should still show.
    4. Turn Airplane Mode off. Within a few seconds the note should say it reached the cloud.
    5. On iPhone, do all of this twice: in Safari, then from the Home Screen (Share → Add to Home Screen).
